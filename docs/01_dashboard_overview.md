**iRAINS Dashboard**

The main landing page after login. Displays a live, interactive rainfall monitoring dashboard for all of India — combining a real-time map, statistics cards, and analysis charts in a single view. HQ, MC, RMC, and Guest users all land here.

---

∙ **Live Station Ticker:** A scrolling marquee at the top of the page continuously displays the Top 5 stations with the highest rainfall recorded for the current day. No interaction needed — the ticker updates automatically on page load.

∙ **Geographic Layer Navigation:** A row of buttons lets you switch the map and statistics between six administrative levels:
    ∙ **Country:** View all-India summary.
    ∙ **Region:** Break down by broad zones (East & North-East, North-West, South Peninsular, Central, etc.).
    ∙ **Subdivision:** View by IMD meteorological subdivisions.
    ∙ **State:** View state-wise rainfall.
    ∙ **District:** View district-level detail.
    ∙ **Block:** View the finest block-level data.
    → Step: Click any layer button → map re-renders and statistics update for that level automatically.

∙ **Date Selection:** A date picker above the map lets you choose any historical date. Step: Click the date field → pick a date → the map and all statistics panels refresh for that date.

∙ **Departure / Actual Mode Toggle:** A switch at the top of the map flips the entire dashboard between two views:
    ∙ **Actual:** Shows raw rainfall in mm with colour bands (No Rain → Extremely Heavy).
    ∙ **Departure:** Shows % deviation from historical normal with colour bands (Large Deficient → Large Excess).
    → Step: Click the toggle → map colours, legend, and statistics all update instantly.

∙ **Navigation Links:** Top-right of the page shows "Home" and "Logout" links. Click "Home" to reload the dashboard. Click "Logout" to end your session and return to the login page.
