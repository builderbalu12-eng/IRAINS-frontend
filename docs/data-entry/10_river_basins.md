**River Basins**

The River Basins page displays a Leaflet map of India's river basins and sub-basins, colour-coded by basin size classification (Very Large / Large / Medium / Small). Users can drill into any basin or sub-basin from dropdowns, view a summary statistics table, and download the map.

Access: All authenticated users.

---

## Step 1 — Select a Basin

∙ **Basin Dropdown:** A dropdown at the top of the page lists all available river basins. Selecting one zooms the map to that basin and filters the sub-basin dropdown below.
    → Step: Click the Basin dropdown → select a basin name (e.g., "Ganga", "Brahmaputra", etc.) → map pans and zooms to that basin, sub-basin dropdown updates.

## Step 2 — Select a Sub-Basin (Optional)

∙ **Sub-Basin Dropdown:** After selecting a basin, this dropdown lists all sub-basins within it. Defaults to **"All"** which shows all sub-basins of the selected basin together.
    → Step: Click the Sub-Basin dropdown → select a specific sub-basin name, or leave as "All" to see the entire basin.

∙ **Map Update:** Selecting a sub-basin highlights just that sub-basin on the map with its colour and zooms to it. Selecting "All" shows all sub-basins of the parent basin.

## Step 3 — Read the Map

∙ **Colour-Coded Basin Map:** Each basin/sub-basin is filled with a colour based on its area classification:
    ∙ Dark Blue (`#08306b`) — **Very Large** (area > 5,000 km²)
    ∙ Blue (`#2171b5`) — **Large** (2,000 – 5,000 km²)
    ∙ Light Blue (`#6baed6`) — **Medium** (500 – 2,000 km²)
    ∙ Very Light Blue (`#c6dbef`) — **Small** (< 500 km²)
    ∙ Grey (`#cccccc`) — **No Data**

∙ **Legend:** A legend panel at the bottom of the map shows the colour key for all four size classifications. Use it to quickly interpret which basins are large vs small.

∙ **IMD Header:** The map header shows the IMD logo, department name, map title, and a compass rose for orientation.

## Step 4 — Read the Summary Table

∙ **Basin / Sub-Basin Statistics Table:** Below or beside the map, a table lists the selected basin(s) or sub-basin(s) with:
    ∙ Sub-basin Name
    ∙ Area (km²)
    ∙ Classification (Very Large / Large / Medium / Small)
    ∙ Region / Location information
    A total or aggregate row may appear at the bottom showing the combined area and count.

## Step 5 — Download the Map

∙ **Map Download (JPEG):** Downloads the current basin map view as a high-resolution JPEG image.
    → Step: Click "Map Download" → JPEG file saves to your computer.

∙ **Map PDF Download:** Downloads the current map as a landscape A4 PDF document.
    → Step: Click "Map PDF Download" → PDF file saves to your computer.

∙ **Reset Position:** Restores the map to the default all-India view if you have panned or zoomed into a specific basin.
    → Step: Click "Reset Position" → map re-centres to show all basins.

∙ **Pan and Zoom (Leaflet built-in):** Use the scroll wheel or pinch gesture to zoom in/out. Click and drag to pan the map to explore any specific basin in detail.
