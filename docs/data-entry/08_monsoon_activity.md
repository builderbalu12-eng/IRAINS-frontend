**Monsoon Activity**

The Monsoon Activity page provides a colour-coded map and summary table showing the current intensity level of monsoon activity across India — classified as Vigorous, Active, Normal, Weak, or Subdued. Users can switch between subdivision-level and district-level views, select any historical date, and download the map for reports.

Access: HQ, MC, and SP users.

---

## Step 1 — Select Date

∙ **Date Picker:** Choose the date for which monsoon activity data should be displayed. The maximum selectable date is today — future dates are blocked.
    → Step: Click the date input at the top → pick a date → proceed to submit.

## Step 2 — Select Geographic Level

∙ **Level Toggle (Subdivision / District):** A select dropdown or toggle lets you switch between:
    ∙ **Subdivision** — colours each IMD meteorological subdivision by its activity level. Gives a broader regional picture.
    ∙ **District** — colours each individual district by its activity level. More granular view.
    → Step: Click the Level dropdown → select "Subdivision" or "District".

---

## Step 3 — Submit and Load

∙ **Submit Button:** Fetches and renders the activity map and summary table for the selected date and level.
    → Step: Click "Submit" → the map redraws with activity colours, and the summary table populates.

## Step 4 — Read the Activity Map

∙ **Colour-Coded Activity Map:** Each subdivision or district is filled with a colour representing the monsoon activity intensity level for that area on the selected date:
    ∙ Red (`#ff0000`) — **Vigorous** — intense, widespread monsoon activity
    ∙ Orange (`#ff9900`) — **Active** — strong but not extreme monsoon activity
    ∙ Green (`#00ff00`) — **Normal** — typical monsoon conditions
    ∙ Yellow (`#ffff00`) — **Weak** — below-normal monsoon activity
    ∙ Grey (`#999999`) — **Subdued** — very little or suppressed monsoon activity
    ∙ Light Grey (`#c0c0c0`) — **No Data** — no report available

∙ **Legend:** A colour-key panel on the map shows all five activity categories with their colours. Refer to it to interpret the map quickly.

∙ **IMD Branding:** The map header displays the IMD logo, department name, the selected date, and a compass rose for orientation.

## Step 5 — Read the Summary Table

∙ **Activity Summary Table (right side or below map):** Lists each subdivision or district with:
    ∙ Name (Subdivision or District)
    ∙ Total Rainfall (mm) for the selected date
    ∙ Activity Status (Vigorous / Active / Normal / Weak / Subdued)
    ∙ Date Range info (if applicable)

## Step 6 — View Activity Chart (Period Selector)

∙ **Period Selector Buttons:** A chart below the map shows activity levels over a time window. Three buttons control the window:
    ∙ **Today** — chart for the selected date only
    ∙ **7 Days** — chart for the last 7 days from the selected date
    ∙ **30 Days** — chart for the last 30 days
    → Step: Click "Today", "7 Days", or "30 Days" → the chart reloads for that time window.

∙ **Activity Chart:** A bar or column chart showing the count or coverage of each activity level (Vigorous/Active/Normal/Weak/Subdued) over the selected period.

## Step 7 — Download the Map

∙ **Map Download (JPEG):** Downloads the current monsoon activity map as a high-resolution JPEG image.
    → Step: Click "Map Download" → JPEG file saves to your computer.

∙ **Map PDF Download:** Downloads the map as a landscape PDF document.
    → Step: Click "Map PDF Download" → PDF file saves to your computer.

∙ **Reset Position:** Re-centres the map to the default India view if you have panned or zoomed.
    → Step: Click "Reset Position" → map re-centres.
