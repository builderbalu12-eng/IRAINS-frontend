**Dashboard Statistics Panel**

A side panel next to the map shows four real-time statistics cards and a 30-day rainfall chart. All values update automatically whenever you change the date, layer, or Actual/Departure mode on the map — no separate submit needed.

---

∙ **Daily Statistics Card:** Displays the aggregate rainfall summary for the currently selected geographic level and date in three numbers:
    ∙ Actual (mm) — measured rainfall
    ∙ Normal (mm) — historical average for that date
    ∙ Departure (%) — how much actual differs from normal
    → Step: Select a layer (e.g., State) and a date → this card instantly reflects totals for that selection.

∙ **Top 5 Blocks / Districts Card:** Lists the five locations with the highest rainfall for the selected date and level. Each entry shows the place name and its recorded rainfall value (mm). Useful for spotting extreme rainfall events at a glance.
    → Step: Switch layers (District or Block) → the top-5 list refreshes to show leaders for that level.

∙ **Highest Recorded Card:** Shows the single highest rainfall value recorded across all stations for the selected date, along with the date it was recorded. Acts as a quick reference for the maximum observed value in the current view.

∙ **30-Day Daily Rainfall Chart:** A combined column-and-line chart covering the last 30 days for the selected location:
    ∙ Blue columns — Actual daily rainfall (mm)
    ∙ Orange/red line — Normal rainfall for the same period
    ∙ Data labels on columns show the departure % for each day
    → Step: The chart defaults to the current layer/date; use the place dropdown inside the chart panel to switch to a different state/region without changing the map layer.

∙ **Place Dropdown (inside chart):** A small dropdown within the 30-day chart lets you pick a specific state or region to plot — without changing the map view. Note: this dropdown is disabled when the Country layer is active (country-level chart has no sub-selection).
    → Step: Open the dropdown → select a state/region → chart reloads for that place.
